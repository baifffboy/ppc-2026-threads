## Введение

STL (Standard Template Library) включает в себя средства для работы с потоками: `std::thread`, `std::async`, `std::future`. Это стандартные инструменты C++, которые не требуют установки дополнительных библиотек.

В отличие от OpenMP и TBB, здесь всё нужно делать руками: создавать потоки, делить работу, ждать завершения. Это сложнее, но даёт полный контроль над происходящим.

В этой работе я использовал `std::thread` для распараллеливания алгоритма Фокса.

## Описание алгоритма (последовательная версия)

Алгоритм Фокса разбивает матрицы на блоки и выполняет num_blocks стадий умножения. Каждая стадия независима от других — это идеальное условие для распараллеливания.

## Схема распараллеливания (STL)

### Основная идея

Стадии алгоритма можно выполнять параллельно, потому что они не зависят друг от друга. Я разбиваю все стадии на группы и каждую группу отдаю отдельному потоку.

### Как это реализовано

```cpp
// Узнаём, сколько ядер в системе
unsigned int hardware_threads = std::thread::hardware_concurrency();
unsigned int num_threads = std::min(hardware_threads, num_blocks);

// Считаем, сколько стадий достанется каждому потоку
int stages_per_thread = num_blocks / num_threads;
int remaining_stages = num_blocks % num_threads;

// Создаём потоки
std::vector<std::thread> threads;
int stage_start = 0;

for (int t = 0; t < num_threads; ++t) {
    int stages_for_this = stages_per_thread;
    if (t < remaining_stages) stages_for_this++;
    
    threads.emplace_back([&, stage_start, stages_for_this]() {
        for (int stage = stage_start; stage < stage_start + stages_for_this; ++stage) {
            ProcessStage(a, b, result, stage, num_blocks, block_size);
        }
    });
    
    stage_start += stages_for_this;
}

// Ждём завершения всех потоков
for (auto& thread : threads) {
    thread.join();
}
```
