## Введение

TBB (Threading Building Blocks) — это библиотека параллельного программирования от Intel. Она даёт готовые инструменты, такие как `parallel_for` и `parallel_reduce`. В отличие от OpenMP, TBB работает на уровне задач, а не на уровне циклов.

Главная фишка TBB — умный планировщик. Если один поток закончил свою работу, он "украдёт" задачу у другого потока. Это называется work-stealing (кража задач). Благодаря этому все ядра всегда заняты работой.

В этой работе я использовал TBB для распараллеливания алгоритма Фокса.

## Постановка задачи

Реализовать параллельную версию алгоритма Фокса с использованием библиотеки TBB и сравнить её производительность с последовательной и OpenMP-версиями.

**Особенности:**

- Нет атомарных операций — каждый поток работает со своими данными
- Автоматическая балансировка нагрузки

## Описание алгоритма (последовательная версия)

Алгоритм Фокса разбивает матрицы на блоки и перебирает стадии. На каждой стадии определённые блоки умножаются и добавляются к результату.

## Схема распараллеливания (TBB)

В TBB-версии я использовал два вложенных `parallel_for`:

```cpp
tbb::parallel_for(0, num_blocks, [&](int stage) {
    tbb::parallel_for(0, num_blocks, [&](int i) {
        int broadcast_block = (i + stage) % num_blocks;
        for (int j = 0; j < num_blocks; ++j) {
            MultiplyBlock(a, b, result, 
                i * block_size, j * block_size, block_size,
                broadcast_block * block_size, j * block_size);
        }
    });
});
```
