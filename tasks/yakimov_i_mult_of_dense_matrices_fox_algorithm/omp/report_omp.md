## Введение

Умножение матриц — одна из самых частых операций в программировании. Она нужна для 3D-графики, нейросетей, научных расчётов. Но если матрицы большие (1024×1024 и больше), то умножение занимает секунды и даже минуты.

OpenMP — это технология, которая позволяет легко распараллелить программу. Достаточно добавить специальную строчку-директиву, и код начнёт выполняться на всех ядрах процессора.

В этой работе я использовал OpenMP, чтобы ускорить умножение матриц по алгоритму Фокса.

## Постановка задачи

**Цель работы:**  
Реализовать параллельную версию алгоритма Фокса для умножения матриц с использованием OpenMP и сравнить её скорость с последовательной версией.

**Что делает программа:**  
Берёт две матрицы из файлов, перемножает их и выдаёт сумму всех элементов результата.

**Ограничения:**
- Матрицы могут быть любого размера
- Для неквадратных матриц используется простой (наивный) алгоритм

## Описание алгоритма (последовательная версия)

Алгоритм Фокса разбивает матрицы на маленькие квадратные блоки (обычно 64×64 или 128×128). Затем он перебирает стадии и на каждой стадии умножает определённые блоки друг на друга. Результат накапливается в результирующей матрице.

В последовательной версии все циклы идут один за другим на одном ядре процессора.

## Схема распараллеливания (OpenMP)

Вот как выглядит основной цикл в OpenMP-версии:

```cpp
#pragma omp parallel for collapse(2)
for (int stage = 0; stage < num_blocks; ++stage) {
    for (int i = 0; i < num_blocks; ++i) {
        for (int j = 0; j < num_blocks; ++j) {
            MultiplyBlock(...);
        }
    }
}
```
