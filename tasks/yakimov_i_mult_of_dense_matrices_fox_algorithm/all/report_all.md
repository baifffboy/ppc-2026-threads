## Введение

В предыдущих работах были созданы отдельные версии алгоритма Фокса для каждой технологии:
- SEQ — последовательная
- OMP — с использованием OpenMP
- TBB — с использованием Intel TBB
- STL — с использованием стандартных потоков

Но хранить четыре отдельные программы неудобно. Лучше сделать одну универсальную версию, которая сама выбирает лучший способ распараллеливания в зависимости от размера матрицы.

В этой работе реализована такая универсальная версия `all`. Она анализирует размер матрицы и автоматически подбирает оптимальный вариант.

## Постановка задачи

**Цель работы:**  
Реализовать универсальную версию алгоритма Фокса, которая автоматически выбирает способ выполнения в зависимости от размера матрицы.

**Что делает программа:**  
Берёт две матрицы из файлов, перемножает их и выдаёт сумму всех элементов результата.

**Особенности:**
- Автоматический выбор размера блока
- Автоматический выбор технологии распараллеливания
- Для маленьких матриц — последовательный код
- Для средних — OpenMP
- Для больших — TBB или STL

## Описание алгоритма (последовательная версия)

Алгоритм Фокса разбивает матрицы на блоки и выполняет несколько стадий умножения. На каждой стадии умножаются определённые пары блоков, результаты накапливаются.

## Универсальная версия (All)

### Автоматический выбор размера блока

В универсальной версии размер блока подбирается в зависимости от размера матрицы:

```cpp
int n = this->matrix_a_.rows;

if (n <= kSmallMatrixThreshold) {
    this->block_size_ = kBlockSizeSmall;    // 32
} else if (n <= kMediumMatrixThreshold) {
    this->block_size_ = kBlockSizeMedium;   // 64
} else {
    this->block_size_ = kBlockSizeLarge;    // 128
}

while (this->block_size_ * 2 <= n && this->block_size_ < kBlockSizeLarge) {
    this->block_size_ *= 2;
}
```
