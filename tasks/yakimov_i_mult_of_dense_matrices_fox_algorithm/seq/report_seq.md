## Введение

Умножение матриц — одна из самых частых операций в программировании. Она нужна для 3D-графики, нейросетей, научных расчётов. Если матрицы маленькие, проблем нет. Но если размер 1000×1000 и больше, то умножение занимает секунды и даже минуты.

Алгоритм Фокса — это способ умножать матрицы быстрее за счёт работы с блоками. Вместо того чтобы бегать по всей матрице, алгоритм разбивает её на кусочки и работает с ними. Это лучше использует кэш-память процессора.

В этой работе сначала сделана последовательная версия (всё на одном ядре). Она нужна как база для сравнения параллельных версий.

## Постановка задачи

**Цель работы:**  
Реализовать последовательную версию алгоритма Фокса для умножения матриц.

**Что делает программа:**  
Берёт две матрицы из файлов, перемножает их и выдаёт сумму всех элементов результата.

**Ограничения:**
- Матрицы могут быть любого размера
- Для неквадратных матриц используется простой (наивный) алгоритм

## Описание алгоритма (последовательная версия)

### Наивное умножение (простой случай)

Самый простой способ — три вложенных цикла:

```cpp
for (int i = 0; i < a.rows; ++i) {
    for (int j = 0; j < b.cols; ++j) {
        double sum = 0.0;
        for (int k = 0; k < a.cols; ++k) {
            sum += a(i, k) * b(k, j);
        }
        result(i, j) = sum;
    }
}
```
